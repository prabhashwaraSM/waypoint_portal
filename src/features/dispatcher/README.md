# Dispatcher feature

Owns Dispatcher-only UI and business logic.

Folders:
- `layout/` — Dispatcher shell and navigation.
- `pages/` — Dashboard, stores, orders, approvals, inventory, dispatch, reports, and fleet pages.
- `components/` — Dispatcher-only reusable components.
- `data/` — Dispatcher/fleet data access and simulation helpers.
- `styles/` — Dispatcher-specific page styles.

Recommended branch: `dispatcher`.

Changes for Loader should not be made here.
