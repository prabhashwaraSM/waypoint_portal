# Driver feature

Owns the phone-first Driver experience.

Folders:
- `pages/` — today's trip, stops, issue reporting and dispatcher replies.
- `styles/` — Driver-specific responsive styling.

The Driver uses the shared Waypoint portal shell with a blue accent. Operational issue data is shared with Dispatcher so driver reports appear in Fleet & Tracking > Driver Notifications.
